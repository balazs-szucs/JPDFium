# Qualification receipt

the bulk evidence lives. This is the **observation** side of the line; the
**expected** side is `reports/FINDINGS-full-sweep.md` and the committed
regression tests.

```
source-controlled expected result  !=  generated observation from one machine
```

Bulk observations (per-case baselines, full `summary*.json`, raw logs, rendered
PNGs, candidate PDFs, failure bundles, `recovery/records/`) are **not** tracked;
they are regenerated by the commands below and archived per run.

## Commands and budgets

```sh
bash native/build-real.sh
./gradlew :jpdfium-natives:jpdfium-natives-darwin-arm64:jar   # classpath loads natives from this jar
./gradlew :jpdfium:qualificationClasspath
bash qualification/build-manifest.sh

# preservation lane (published gate, raw byte-exact text oracle)
python3 qualification/qualify.py --group all --limit 0 \
  --ops save,font,font-plan,preserve --idempotence --timeout 60

# recovery lane (separate report, never overwrites the preservation summary)
python3 qualification/qualify.py --lane recovery --group general   --limit 0 --timeout 60
python3 qualification/qualify.py --lane recovery --group generated --limit 0 --timeout 60
```

Budget: one JVM per (input, operation); `--timeout 60 s` per launch (Python-side,
no GNU `timeout`); `-Xmx512m` bounds the heap only, not native allocations;
render comparison is limited to documents ≤ 25 pages and is recorded as
`render_scope`.

Open regression of record: **`pdfjs_ZapfDingbats.pdf`** — the planner
synthesised a 1-byte ASCII identity `/ToUnicode` (`0x4B -> U+004B`) for a
standard-14 `/ZapfDingbats` font with no `/FontDescriptor`/`/Encoding`
(document labels and poppler's own fallback say `0x4B -> U+272B`). Fixed by
declining the font (`SYMBOLIC_FONT_UNSUPPORTED`, commit `99bd09ca`) plus
`FontSymbolicEncodingTest`. See `reports/FINDINGS-full-sweep.md` for the full
classification of all eleven flagged cases.
